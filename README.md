# E747 EmbeddedML Abschlussprojekt

Dieses Repo dient als Template für ihr Projekt.

Folgende Dinge sind im Rahmen des Projekts einzureichen:

- Projektposter
- Quellcode
- Video

Im Ordner `0_Vorlagen` finden Sie eine Vorlage für das **Projektposter**, welches Sie erstellen sollen. Bitte checken Sie das fertige Poster sowohl als Powerpoint- als auch als exportierte PDF-Datei wieder hier im Repo ein.

Ihren eigens entwickelten **Quellcode** checken Sie bitte im Ordner `1_Quellcode` ein.

**Größere Datensätze**, die Sie bspw. für das Training neuronaler Netze verwendet haben, können mit einem Verweis bzw. Link hier dokumentiert werden.

Das zu erstellende **Video** können Sie entweder über Youtube oder bspw. Dropbox hochladen und den Link hier in dieser README.md hinterlegen. Bitte beachten Sie, dass die Datei keinen externen Zugriff bekommt. Bei Youtube können Sie die Videos als *Nicht gelistet* markieren. Dann hat man nur Zugriff, wenn man den Link kennt.

**Wichtig:** Im Video präsentieren sie bitte ihr Projekt inkl. Problemstellung, Umsetzung und Vorstellung der umgesetzten Ergebnisse.

Außerdem können Sie diese README für eine Kurzbeschreibung ihres Projektes und weitere wichtige Informationen nutzen.
